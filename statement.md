Problem Statement

Most first time users and students, however, don't really want to deal with complex software or powerful libraries just to practice the basic operations and to see how to perform calculations on matrices. This project offers a solution by developing a minimalistic calculator that runs from a terminal and performs the basic operations on both matrices and scalar values.

Scope of the Project

This is a command line calculator project. It covers:

*Add, subtract, multiply and divide two numbers
* Preventing division by zero with a meaningful error message
* Performing addition of two 22 matrices
* Performing subtraction of two 22 matrices
* Performing multiplication of two 22 matrices
* Have the program show the results of the calculation in the console window.
* An option to have a menu-driven interface for convenient use.

In-scope (for this version): larger matrix sizes, matrix operations (determinant, inverse) or any other matrices functions, data storage (variables, groups of variables), graphical user interface, scientific calculator function, storage of previous calculations and outputs. Which are potentially out of scope and can be implemented as future features.

Target Users

* Students studying to learn to code in basic Python and mathematics
* Beginners practicing arithmetic and matrix operations
* Those looking for a straightforward terminal calculator
* Novice programmers

High-Level Features

* Menu-based calculator interface

* four elementary operations of algebra: +, –, x, /

* Division-by-zero error handling

* 2 by 2 matrix addition

* 2 by 2 matrix subtraction

* 2 by 2 matrix multiplication

* User input through the terminal
* Clear display of calculated results
